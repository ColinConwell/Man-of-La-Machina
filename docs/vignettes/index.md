# Vignettes

Each vignette walks through one task from start to finish. They assume you have followed [Getting started](../getting-started.md).

| Vignette | You will | Needs the private archive |
| --- | --- | --- |
| [Try it with invented material](invented-material.md) | Run the complete interface on a small invented archive | No |
| [Reopen a moment](reopen-a-moment.md) | Enter the archive, shape the model's context, and write the next turn | No, with invented material |
| [Compare two contexts](compare-two-contexts.md) | Send one turn twice and see what withholding the past changes | No, with invented material |
| [Run a counterfactual experiment](counterfactual-experiment.md) | Plan, rehearse, and run simulated conversations, then read the results | For live runs |
| [Choose where a visit begins](choose-beginnings.md) | Mark the turns a visitor can start from | Yes |
| [Present the project deck](project-deck.md) | Present or edit the interactive slide deck | No, with the example deck |

# Sound Studio: Layered Narration And Evolving Voice Effects

Research and implementation date: October 29, 2026.

## Research Question

Can independently generated readings and programmatically changing effects produce expressive narration while preserving intelligibility, timing, and a reproducible record of the transformation? Sound Studio provides a local laboratory for that question. Its implementation establishes an experimentation workflow; it does not establish that any voice or effect recipe produces a particular emotional response in listeners.

## Library Comparison And Selection

| Component | Evidence And Role | Implementation Boundary |
| --- | --- | --- |
| [Tone.js](https://tonejs.github.io/) | Web Audio scheduling and effects support synchronized browser audition. | All layers share one audio-context start time. Live parameter updates use a control-rate clock. Preview algorithms are identified separately from rendering. |
| [WaveSurfer](https://wavesurfer.xyz/) | Waveforms and extensible regions, envelopes, and spectrogram displays support audio navigation. | WaveSurfer displays precomputed peaks and follows the shared clock; it does not run independent track players. Automation and effect regions are studio controls. Spectrograms are computed from saved audio. |
| [Pedalboard 0.9.26](https://spotify.github.io/pedalboard/reference/pedalboard.html) | Built-in effects and audio processing provide the offline effects rack. | Built-ins are used; VST3 and Audio Unit hosting remain future work. Automated plugin parameters update in small blocks while preserving processor state. |
| [Rubber Band](https://breakfastquay.com/rubberband/usage.txt) | Pitch maps, time maps, and formant-preserving processing support voice transformations and alignment. | Pitch, stretch, and alignment are rendered before playback. Dynamic pitch mode can vary output length; the renderer normalizes final length. Timing fixtures check transient behavior. |
| [WhisperX](https://github.com/m-bain/whisperX) | Forced alignment provides word timings when provider timestamps are absent. | Only known-text alignment is required. Processing starts on CPU, with optional dependencies and cached alignment weights. Unmatched words and excessive stretch ratios require review. |
| [FFmpeg](https://ffmpeg.org/ffmpeg-filters.html) | Audio decoding and format conversion provide a common PCM representation and exports. | WAV originals or provider bytes remain immutable; the renderer produces saved derivatives. Peak and RMS measurements are calculated from decoded samples. Integrated LUFS measurement is not yet exposed. |
| [VADER](https://github.com/cjhutto/vaderSentiment) | A lexicon and rules provide inexpensive local sentiment features. | Scores are interpretations, especially for literary language. Structural features and editable/model-generated feature tracks provide alternatives. |

Using only browser DSP would make previews convenient but would complicate reproducible exports and alignment. Using only offline processing would make routine effect exploration slow. The selected hybrid preserves responsiveness while making backend renders authoritative. Shared parameter names do not imply algorithmic equivalence: reverb networks, filter designs, nonlinear transfer curves, and compressor envelopes can differ.

## Provider Comparison

| Provider | Documented Interface | Studio Controls And Evidence |
| --- | --- | --- |
| [OpenAI Speech](https://developers.openai.com/api/reference/resources/audio/subresources/speech/methods/create) | Speech models, voice selection, delivery instructions where supported, speed, and output format. | The app's exact Cedar/Marin model and instruction constants are available as baseline presets. Custom voice IDs can be supplied. Instruction controls are absent for legacy TTS models. |
| [ElevenLabs With Timestamps](https://elevenlabs.io/docs/api-reference/text-to-speech/convert-with-timestamps) | Voice settings, pronunciation dictionaries, normalization, continuity text, and character timing. | Original and normalized timing responses are retained. Unsupported speaker boost is omitted for v3. Seeds are recorded but should not be interpreted as a guarantee of identical output. |
| [Cartesia SSE](https://docs.cartesia.ai/api-reference/tts/sse) | Versioned streaming speech, voice and delivery configuration, and timestamp events. | Sonic 3.6/3.5 and Sonic 3 use model-appropriate voice payloads/API versions. Word and optional phoneme events are retained. Emotion controls are limited to the supported adapter/model combination. |
| [Gemini Speech](https://ai.google.dev/gemini-api/docs/speech-generation) | Single- and multi-speaker speech with delivery guidance and vocal annotations. | Gemini 3.8 uses Interactions speech metadata; 2.5 models use the generateContent speech configuration. Speaker assignments and inline vocal annotations can be included in the input. |

One short, invented passage was generated once with each default provider on this machine. All four requests completed, their audio decoded successfully, and their receipts and distinct sample identities were retained. This is bounded adapter evidence, not a comprehensive model/voice/locale benchmark or a quality ranking. No private archive text was needed for these live checks.

## Experimental Workflow

The source snapshot records the exact spoken text, source identity/version, extraction options, and hash. Chunking retains every character and its source offset. Repeated takes create distinct jobs and samples. The default sweep varies one numeric parameter; explicit combinations of chosen inputs and configurations form a grid. Limits are checked before any job is submitted.

Each project contains layers, ordered effects, envelopes, and automation lanes. Originals are independent from versioned recipes and rendered derivatives. Starting recipes demonstrate detuned unison, contrasting readings, evolving space, and a text-driven pitch lane. Local analysis is reusable; changing the text invalidates dependent feature mappings. Editable JSON/CSV tracks allow different feature definitions, while sentence anchors connect feature values to audible parameters.

Alternative takes first receive provider or local word timings. Reference alignment accepts only monotone anchors with local stretch ratios between 0.5 and 2. A live contrasting-voice example exceeded that bound at some word anchors and was correctly flagged. Explicitly edited sentence or word anchors provide a review path; the original remains available.

## Validation And Limitations

The 39-test isolated Python 3.11 suite covers all 16 effects, exact long-text partitioning, provider/model payload controls, repeated-take identity, budget limits, cancellation/restart behavior, feature corrections, missing alignment coverage, checksums, catalog reconstruction, storage-prefix protection, and API origin boundaries. Known tones and impulses check pitch, stereo gain, tails, clipping, dynamic-pitch onset, and time-map placement. The time-map fixture exposed a Rubber Band R3 zero-anchor issue; omitting the engine's implicit zero anchor fixed it.

Browser acceptance exercises generate/import, duplicate layers, automation points, dry comparison, authoritative rendering, save/reload, sample inspection, measured spectrograms, light/dark appearance, keyboard navigation, and a long text input at a mobile viewport. The 172 main-application backend regressions and two browser workflows passed separately. Strict documentation and production-bundle isolation checks also passed. Local WhisperX alignment of the live OpenAI example completed on CPU with 17 words and no unmatched words.

Real S3 transfer was not verified because the available Railway connection did not authenticate and local S3 credentials were absent. Controlled S3 tests validate round trips, failed upload handling, checksum rejection, shared-object protection, and preservation of foreign prefixes. Storage remains optional; local generation, editing, playback, and rendering are available independently.

This is a first local implementation. It does not yet expose integrated LUFS metering, a general-purpose DAW arrangement editor, sample-accurate loop seams, live Rubber Band processing, voice-clone enrollment, external plugin hosting, hosted multi-user access, or main-app integration. In-flight provider calls can be billed even after cancellation. Very long mixes are memory-intensive. Perceptual quality, speaker identity preservation, and the validity of inferred emotions require listening and human review.

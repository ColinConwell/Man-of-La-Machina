# Research and Discussion Reports

Reports preserve the reasoning behind high-level design choices. Use a stable sequential number, date, and descriptive filename: `NNN-YYYY-MM-DD-topic.md`. Add each report to this index. Distinguish sourced findings, historical uncertainty, interpretation, proposals, and implemented behavior; link primary sources beside claims and record the research date. Keep private source passages and identifying personal information out of reports committed to this repository.
